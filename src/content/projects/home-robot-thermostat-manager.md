From June to August 2025, I built a motorized Raspberry Pi robot that measured temperatures in different rooms. It used a custom obstacle-avoidance algorithm and real-time ultrasonic sensor data to move around.

The system combined those measurements with utility and weather API data to optimize HVAC scheduling. Estimated energy costs fell by 15%.

[View the code on GitHub](https://github.com/Harshit-Saini0/smart-robot).
