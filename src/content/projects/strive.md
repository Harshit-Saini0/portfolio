- Led UI/UX design and API integration teams.
- Used Git for version control, enabling efficient collaboration, code reviews, and iterative development.
- Prepared for deployment and testing with Aggie Coding Club (300+ students).

No public build available yet — deployment and testing with the Aggie Coding Club community is ongoing.
